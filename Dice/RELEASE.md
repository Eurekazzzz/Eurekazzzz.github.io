## 1. 用户反馈摘要

### 1.1 核心问题

| # | 反馈 | 根因 | 严重程度 |
|---|------|------|---------|
| 1 | "几乎所有预期功能都报错" | 异常吞没 + 多处逻辑竞态 + UI 事件绑定不健壮 | P0 |
| 2 | "界面臃肿，信息爆炸" | 9 个 card 全部平铺在单页面，移动端需大量滚动 | P0 |
| 3 | "标准流程跑不通" | 设置→投掷→确认结果 的核心流程无明确步骤引导 | P0 |

### 1.2 用户改进要求

- 页面分为**两步流程**：先进设置页配置，再进入投掷页
- 投掷页只保留：当前骰子设置摘要 + 投掷按钮 + 结果展示（含历史）
- **高级功能藏在折叠菜单**中，不占据屏幕空间
- 切换骰子属性需返回设置页

## 2. v2.0 → v2.1 Bug 修复清单

### 2.1 已修复

| Bug | 描述 | 修复方式 |
|-----|------|---------|
| 暗骰揭示渲染丢失 | `renderResultDisplay` 创建的骰子元素被 `revealDarkRoll` 清空重建 | 拆分为 `renderDice` + `revealDiceValues`，揭示时只翻转而非重建 |
| d100 颜色错误 | 展开后十位/个位 faceCount=10，取到 d10 紫色 | 新增 `d100` 标记字段，渲染时优先取 `#5856d6` |
| 键盘快捷键冲突 | 输入框聚焦时快捷键不生效，但空格会干扰 | 统一判断 `activeElement.tagName`，输入框内仅 Esc 生效 |
| 预设加载后报错 | `loadPreset` 设置输入框后直接调无参 `roll()`，输入框可能为空 | 预设直接解析为 config 传给 `doRoll(cfg)` |
| 异常吞没 | `catch(e)` 只弹 toast 不打印日志 | 所有 catch 加 `console.error` |
| 动画竞态 | `animateCountUp` 在 `textContent` 已设置后启动 | 移除 countUp 动画，简化为直接显示 |
| 自定义面值负数解析 | `2d[-1,0,1,2]` 首个负号被错误处理 | 统一 sign 标记先读取，再读数值 |
| 表达式拼接错误 | `2d6+-1d20` 等负号标签拼接异常 | 检查 label 是否以 `-` 开头再决定加号 |
| isRolling 锁死 | 异常路径下 `isRolling` 可能不释放 | 使用 try/finally 风格，`S.rolling = false` 始终执行 |

### 2.2 架构重构

| 维度 | v2.0 | v2.1 |
|------|------|------|
| 页面结构 | 单页面 9 个 card | 双页面（设置 + 投掷） |
| 类设计 | 7 个 class（DiceEngine/Parser/Animation/Sound/History/Preset/DiceApp） | 模块化单对象 `DiceEngine` + `S` 状态 + 渲染函数 |
| 骰子动画 | CSS 3D cube + card-flip 混合 | 统一 card-flip + shake 动画 |
| CSS 行数 | ~800 行 | ~320 行 |
| JS 行数 | ~1400 行 | ~500 行 |
| 总行数 | 2265 行 | ~1200 行 |

## 3. v2.1 功能清单

### 3.1 设置页（Step 1）

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 快捷骰子网格 | d4/d6/d8/d10/d12/d20/d100，点击直接进入投掷页并自动投掷 | 核心 |
| 骰子数量 | 步进器 1-99 | 核心 |
| 面数 | 步进器 2-1000 | 核心 |
| 修正值 | 步进器，支持负数 | 核心 |
| 面值模板 | 标准 [1..N] / 命运 [-1,-1,0,0,1,1] / 自定义 | 核心 |
| 自定义面值 | textarea，每行一个整数 | 核心 |
| 投掷模式 | 7 种：普通/优势/劣势/去最低/去最高/成功计数/爆裂骰 | 核心 |
| 模式参数 | 动态显示（阈值/丢弃数/追加数） | 核心 |
| **确认→进入投掷** | 主按钮，读取设置并跳转 | 核心 |
| ─── 高级功能（折叠） ─── | | |
| CoC 检定 | 技能值输入 + d100 检定按钮 | 高级 |
| 预设管理 | 内置 4 个 + 用户自定义，chip 样式，增删 | 高级 |
| 表达式输入 | 文本框 + 投掷按钮，支持 `2d6+1d20+3`、`4dF`、`2d[-1,0,1]` | 高级 |
| 暗骰模式 | 开关 | 高级 |
| 快捷键帮助 | 弹窗显示 | 高级 |
| 音效开关 | 切换按钮 | 高级 |

### 3.2 投掷页（Step 2）

| 功能 | 说明 |
|------|------|
| 配置摘要 | 顶部显示当前表达式 + 模式标签 |
| 骰子展示区 | 翻转动画，颜色区分骰子类型，dropped/exploded 标记 |
| 结果展示 | 总和 + 表达式 + 最高/最低/丢弃/成功数/CoC 判定 |
| 投掷按钮 | 大号按钮，投掷中自动禁用 |
| 历史记录 | 最近 50 条，时间 + 表达式 + 各骰值 + 总和，可清空 |
| 暗骰覆盖 | 开启后结果隐藏，点击揭示 |
| 音效/分享 | 导航栏按钮 |
| 返回设置 | ← 按钮返回设置页修改配置 |

### 3.3 技术特性

| 特性 | 实现 |
|------|------|
| 随机数 | `crypto.getRandomValues()` (CSPRNG) |
| 音效 | Web Audio API 合成（白噪声脉冲 + 正弦波），无外部文件 |
| 持久化 | `localStorage` 存储预设和设置 |
| URL 分享 | `?expr=2d6+3&mode=success` 参数编码 |
| 快捷键 | 数字键投掷、Space 重掷、T=d20、H=d100、Esc 返回 |
| 响应式 | ≤380px 缩小骰子和字号 |
| 扩展预留 | `DiceEngine` 可覆写随机源；`S.history` 可发射事件供 WebSocket 监听 |

## 4. 测试用例

### 4.1 核心流程（必须通过）

| # | 步骤 | 预期结果 |
|---|------|---------|
| T1 | 打开页面 → 看到设置页 | 显示快捷骰子网格 + 自定义配置 + 模式选择 |
| T2 | 点击 d20 快捷按钮 | 自动跳转投掷页，执行 1d20 投掷，显示 1-20 之间结果 |
| T3 | 点击 ← 返回设置 → 修改数量为 3，面数为 6 → 点击确认 | 跳转投掷页，显示配置 `3d6` |
| T4 | 在投掷页点击投掷按钮 | 显示 3 颗骰子翻转动画，结果总和 |
| T5 | 再次点击投掷 | 新结果覆盖旧结果，历史记录 +1 |
| T6 | 检查历史记录 | 显示之前投掷的时间、表达式、骰值、总和 |
| T7 | 点击清空历史 | 历史清空 |

### 4.2 自定义骰子

| # | 步骤 | 预期结果 |
|---|------|---------|

## 5. 已知限制（不阻塞交付）

| 项目 | 说明 |
|------|------|
| 3D 骰子 | 使用 card-flip 而非真 3D 多面体，视觉效果够用 |
| 暗骰揭示 | 揭示后重新渲染骰子，无翻转动画（可接受） |
| 概率分布图 | PRD P2 功能，未实现 |
| 多人联机 | 预留扩展点，未实现 |
| 混合骰池 UI | 表达式输入支持（`1d20+2d6`），但自定义面板仅支持单一规格 |
| 文字面值 | PRD 确认不需要 |
| 暗骰模式 | 仅本地隐藏，不防审查元素（GM 信任模式） |

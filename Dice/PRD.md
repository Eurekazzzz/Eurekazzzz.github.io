# 骰子模拟器 — 产品需求文档（PRD）

**产品名称**：骰子模拟器（Dice Simulator）  
**版本**：v1.0  
**最后更新**：2026-07-06  
**作者**：Eurekazzzz  

---

## 1. 产品概述

### 1.1 定位

一款面向桌游与跑团（TRPG）玩家的在线骰子投掷工具。支持自定义骰子数量、面数、每面数值，覆盖从经典 D20 系统到任意自定义骰池的投掷场景。

### 1.2 核心价值

- **灵活性**：不局限于标准骰子（d4/d6/d8/d10/d12/d20/d100），支持完全自定义面数和面值的骰子。
- **易用性**：快速预设一键投掷，同时保留深度自定义能力。
- **透明性**：每颗骰子结果独立展示，投掷历史可追溯。

### 1.3 技术约束

- 纯前端实现（HTML + CSS + JS），单文件自包含，无后端依赖。
- 与现有项目风格保持一致（iOS 设计语言、毛玻璃效果、原生 JS）。

## 2. 目标用户与使用场景

### 2.1 用户画像

| 用户类型 | 描述 | 典型需求 |
|---------|------|---------|
| 跑团玩家 | DND/CoC/PF 等 TRPG 玩家 | 快速投掷标准骰（d20、d100 等），带修正值 |
| 跑团主持人（KP/DM） | 需要同时投掷多颗不同骰子 | 批量投掷、骰池管理、快速查看结果分布 |
| 桌游玩家 | 任何需要骰子的桌游 | 自定义面数（如 d6 双方格骰）、自定义面值 |
| 游戏设计师 | 设计新游戏时需要测试骰子系统 | 自定义每面数值、查看概率统计 |

### 2.2 典型场景

1. **DND 战斗**：玩家攻击掷 `1d20+5`，命中后掷 `2d6+3` 伤害。
2. **CoC 技能检定**：掷 `1d100` 对比技能值，判断成功/失败等级。
3. **骰池系统**（如 Shadowrun、WoD）：掷 `8d6`，统计 ≥5 的成功数。
4. **自定义桌游**：使用 6 面骰但面值为 `[1, 1, 2, 2, 3, 3]`。
5. **非标准骰子**：Fudge/FATE 骰（面值为 `[-1, -1, 0, 0, +1, +1]`）。
6. **GM 暗骰**：快速生成多个 NPC 的随机属性值。

## 3. 功能需求

### 3.1 核心功能（P0 — 必须实现）

#### F1：标准骰子快速投掷

- 提供标准骰子快捷按钮：**d4、d6、d8、d10、d12、d20、d100**
- 点击即掷 1 颗对应骰子，立即显示结果
- d100 使用两颗 d10（十位 + 个位）模拟，而非真正的 100 面骰

#### F2：自定义骰子数量与面数

- 用户可设定骰子数量（1 ~ 99 颗）
- 用户可设定每颗骰子的面数（2 ~ 1000 面）
- 默认面值为 `1, 2, 3, ..., N`（N = 面数）
- 支持一次性投掷多颗相同规格的骰子（如 `3d6`）

#### F3：自定义面值

- 用户可编辑每颗骰子每一面的具体数值
- 支持整数（含负数和零）
- 不同骰子可以有不同面值配置（如骰子 A 为 `[1,2,3,4,5,6]`，骰子 B 为 `[0,0,1,1,2,3]`）
- 提供预设模板：
  - 标准骰：`[1, 2, 3, 4, 5, 6]`
  - Fudge 骰：`[-1, -1, 0, 0, +1, +1]`
  - 自定义：用户自由填写

#### F4：骰子表达式解析

- 支持标准骰子表达式语法：`XdY+Z`
  - `X` = 骰子数量
  - `Y` = 面数
  - `Z` = 修正值（可选，支持 `+` 和 `-`）
- 示例：`2d6+3`、`1d20-2`、`4d6`
- 提供表达式输入框，回车即掷

#### F5：结果展示

- 每颗骰子的结果**独立显示**（如掷 `3d6` 显示 `[4, 2, 6]`）
- 显示**总和**（含修正值）
- 显示本次投掷的**最高值**和**最低值**
- 骰子结果带有滚动/翻转动画效果

#### F6：投掷历史

- 记录最近 **50 次**投掷结果
- 每条记录包含：时间戳、表达式、各骰子结果、总和
- 支持清空历史
- 历史面板可折叠/展开，不干扰主操作区

---

### 3.2 扩展功能（P1 — 优先实现）

#### F7：骰子预设方案

- 用户可保存自定义骰子配置为预设方案
- 每个方案包含：名称、骰子数量、面数、面值配置
- 支持方案的增删改查
- 内置常用预设：
  - `DND 属性掷骰`：`4d6 去最低`
  - `CoC 技能检定`：`1d100`
  - `Shadowrun 骰池`：`Xd6 数成功（≥5）`
  - `Fudge 骰`：`4dF`（面值为 `[-1,-1,0,0,+1,+1]`）
- 预设数据存储在 `localStorage`

#### F8：高级投掷模式

- **优势/劣势**（Advantage/Disadvantage）：掷两次取高/低，DND 5e 常用
- **去最低**（Drop Lowest）：如 `4d6 去最低` 用于 DND 角色创建
- **去最高**（Drop Highest）
- **成功计数**（Success Count）：设定阈值，统计 ≥ 阈值的骰子数量（适用于骰池系统）
- **爆炸骰**（Exploding Dice）：掷出最大值时追加一颗骰子

#### F9：CoC 检定结果判定

- 掷 `1d100` 时，输入技能值自动判定结果等级：
  - 大成功（01）
  - 极难成功（≤ 技能值 / 5）
  - 困难成功（≤ 技能值 / 2）
  - 普通成功（≤ 技能值）
  - 失败（> 技能值）
  - 大失败（96~100，且技能值 < 50 时为 100）

| 功能 | 说明 |
|------|------|

### 4.2 设计规范

| 属性 | 值 |
|------|-----|
| 风格 | 与主页一致的 iOS 设计语言 |
| 主色调 | `#007aff`（iOS Blue） |
| 圆角 | `18px`（卡片）、`12px`（按钮） |
| 背景 | `#f9f9f9` + 毛玻璃卡片 |
| 字体 | `-apple-system` 系统字体栈 |
| 动画 | 骰子滚动翻转动画（CSS 3D transform），时长 0.6~1s |
| 响应式 | 移动端优先，≤600px 自适应布局 |

### 4.3 骰子视觉表现

- 每颗骰子以**圆角方块**呈现，显示面值数字
- 不同面数的骰子用不同颜色区分（d4 红、d6 蓝、d8 绿、d10 紫、d12 橙、d20 金）
- 投掷时骰子执行 3D 翻转动画，动画结束后揭示结果
- 自定义面值的骰子显示用户设定的数值

## 5. 数据模型

### 5.1 骰子配置

```
DiceConfig {
  id: string              // 唯一标识
  count: number           // 骰子数量（1~99）
  faces: number           // 面数（2~1000）
  faceValues: number[]    // 每面数值，长度 = faces，默认 [1..faces]
  modifier: number        // 修正值，默认 0
  label: string           // 可选标签，如 "力量检定"
}
```

### 5.2 投掷结果

```
RollResult {
  timestamp: number       // 时间戳
  config: DiceConfig      // 本次使用的配置
  results: number[]       // 每颗骰子的结果（取到的面值）
  total: number           // 总和 + 修正值
  max: number             // 最高值
  min: number             // 最低值
  expression: string      // 表达式字符串，如 "2d6+3"
  dropped: number[]       // 被丢弃的骰子（去最高/低时使用）
}
```

### 5.3 预设方案

```
Preset {
  id: string
  name: string            // 方案名称
  configs: DiceConfig[]   // 骰子配置列表
  mode: RollMode          // 投掷模式（普通/优势/去最低等）
  successThreshold?: number  // 成功计数阈值
}
```

## 6. 非功能需求

| 维度 | 要求 |
|------|------|
| 性能 | 99 颗骰子同时投掷，动画完成 < 2s，无卡顿 |
| 随机性 | 使用 `crypto.getRandomValues()` 提供密码学安全的随机数 |
| 可访问性 | 按钮可聚焦、支持键盘操作、结果区域有 `aria-live` |
| 离线可用 | 纯前端静态页面，加载后无需网络 |
| 存储 | 预设方案存 `localStorage`，提供导出/导入 JSON |
